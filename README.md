# LingLink

![LingLink](logo.png)

LingLink учит язык через чтение настоящих текстов. Знакомые слова и только что выученные остаются на изучаемом языке, а остальное пока читается на уже знакомом. Текст постепенно становится ближе к языку, который человек учит.

## Как этим пользуются

Читатель выбирает язык интерфейса и изучаемый язык, открывает текст и отмечает слова, которые уже знает. Дальше программа ведёт чтение небольшими партиями: чаще всего по пять новых слов за раз. В тексте известное и текущая партия показаны на изучаемом языке, неизвестное остаётся на знакомом. После партии эти слова закрепляются и встречаются в других текстах.

Автор добавляет текст. Сообщество предлагает переводы отдельных слов и устойчивых конструкций, голосует за варианты и может добавить цельный перевод.

Есть два способа чтения:

- **От знакомого языка.** Оригинал написан на языке, который человек уже понимает. По мере обучения слова в нём заменяются на изучаемый язык.
- **От изучаемого языка.** Оригинал написан на изучаемом языке. Новичок читает его по готовому переводу на знакомый язык, а выученные места возвращаются к оригиналу.

## Из чего состоит

Клиент — Vue 3, TypeScript и Vite. Состояние хранит Pinia, экраны — Vue Router, тексты интерфейса — vue-i18n. Данные и вход в аккаунт идут через Firebase. Мобильная сборка для Android собирается через Capacitor.

Исходники клиента лежат в каталоге `linglink`.

## Запуск

```sh
cd linglink
npm install
npm run dev
```

Нужен Node.js 22.18 или новее (подходит и 24.12+). Настройки Firebase задаются локально в `linglink/.env` переменными `VITE_FIREBASE_*` и `VITE_REPOSITORY_MODE`. Этот файл в репозиторий не входит.

Проверка:

```sh
npm run type-check
npm run lint
npm run test:unit
```
